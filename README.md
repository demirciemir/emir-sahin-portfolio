# 🎬 Emir Şahin - Portfolio & Video Production

![Emir Şahin Portfolio](public/assets/img/general/favicon.png)

A modern, fast, and fully dynamic portfolio website built for professional videographer and content creator **Emir Şahin**. Designed to showcase creative video productions, commercial shoots, and digital content with a premium user experience.

🌐 **Live Website:** [emirvisuals.com](https://emirvisuals.com)

---

## ✨ Features

- **Dynamic Video & Image Gallery:** GLightbox integration for seamless video playbacks and image viewing directly from the portfolio grid.
- **Advanced Filtering System:** Sort projects by brand/client or by video length (Short Videos / Long Videos) instantly without page reloads.
- **Custom Admin Dashboard:** A secure backend to easily upload new projects, manage clients, and update portfolio items without touching the code.
- **Multi-Language Support:** Fully translated interface supporting both English (EN) and Turkish (TR).
- **SEO & AI Optimized:** Includes automated `sitemap.xml`, `robots.txt`, `llms.txt`, and rich Open Graph meta tags for perfect search engine and AI crawler indexing.
- **Ultra-Fast Performance:** Zero heavy frameworks on the frontend. Built with pure, optimized Vanilla JavaScript and CSS to ensure instant load times.

---

## 🛠️ Tech Stack

**Backend:**
- [Laravel 11](https://laravel.com/) (PHP)
- SQLite (Lightweight, file-based database perfectly suited for portfolio sites)

**Frontend:**
- HTML5, CSS3, Vanilla JavaScript
- Bootstrap (for layout structuring)
- [GLightbox](https://biomacles.github.io/glightbox/) (for media popups)
- Phosphor Icons & FontAwesome
